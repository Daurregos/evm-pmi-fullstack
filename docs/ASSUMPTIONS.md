## Supuestos con mayor riesgo

- **Modelo temporal:** toca persistencia, API e interfaz a la vez y bloquea la curva S, el gráfico de mayor valor diagnóstico de EVM.
- **Borrado físico en cascada:** es irreversible; si resulta falso, los datos ya se perdieron y ninguna corrección posterior los recupera.
- **BAC del proyecto como suma de sus actividades:** cambia el modelo de dominio y obliga a rehacer la consolidación completa.
